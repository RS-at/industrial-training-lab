# S7-1200 传送带 PLC 交互仿真 · 实验 01

这是 **纯离线 HTML 教学逻辑仿真**，无需软件安装，不生成真实可下载到 PLC 的 TIA Portal 工程。标准接线已预先连接，学生可以先测试启动与停止，再删除导线重新接线。页面使用 SVG 渲染货物、传送带、光电传感器与电机，JavaScript 以 50 ms 周期模拟 PLC 逻辑扫描。

## 快速开始

1. 用 Windows Edge/Chrome 或手机现代浏览器打开 `西门子S7-1200_传送带PLC交互仿真_v1.html`。
2. 按绿色 **SB1 启动**。传送带开始运动，货物经过 B1 光电传感器时计数一次。
3. 将虚拟速度设为 **1/4**，比较与正常速度的差别。
4. 按停止、急停，或模拟热继电器过载、光电传感器断线/粘连，观察数字量输入、输出和梯形图状态。
5. 选择“清空接线”，自行点击现场设备端子和 PLC I/O 端子配线。误接线将提示并被教学安全规则拦截；“一键标准接线”可恢复初始状态。

## I/O 定义

| 地址 | 现场设备 | 信号意义 |
|---|---|---|
| I0.0 | SB1 启动按钮 NO | 按下=1，松开=0 |
| I0.1 | SB2 停止按钮 NC | 松开=1，按下=0 |
| I0.2 | S0 急停按钮 NC（教学输入） | 释放=1，按下=0 |
| I0.3 | B1 光电传感器 PNP | 检测到包裹=1 |
| I0.4 | FR1 热继电器 NC | 正常=1，过载动作=0 |
| Q0.0 | KM1 接触器控制 | 1=电机允许运转 |
| Q0.1 | HL1 运行指示灯 | 1=运行 |
| Q0.2 | HL2 故障指示灯 | 1=急停/过载故障 |

说明：本实验的 PLC DI/DQ 为**逻辑信号示意**，不是 CPU 1214C 实物端子的完整安全接线图；真实设备应根据具体订货号、输入类型、驱动方式和厂家的手册核验。急停实际应采用适当的安全回路/安全设备，不能仅依靠普通 PLC 程序。继电器线圈应按额定功率和隔离需求选型，不能把 Q0.0 直接接三相电机。

## 主要逻辑

```text
M0.0 := I0.1 AND I0.2 AND I0.4 AND (I0.0 OR M0.0)
Q0.0 := M0.0
Q0.1 := Q0.0
Q0.2 := NOT I0.2 OR NOT I0.4
IF RisingEdge(I0.3) AND MotorRunning THEN C0 := C0 + 1
```

## 速度与仿真的边界

页面的 `1/4` 速度是**虚拟驱动器速度设定**，目的是比较物料输送速度。真实普通 PLC 的单个 Q0.0 开关量只能提供启停命令；要通过 S7-1200 调速，还需要变频器/伺服驱动器，结合模拟量、脉冲或工业通信进行设定。

本实验不计算电机电磁转矩、加速度曲线、皮带打滑、生产线动力学，也不能导入 TIA Portal 直接控制硬件。它适合零基础教学和验证简化的 PLC 信号逻辑。可在后续版本中增加更准确的电机/变频器/传感器模型、Tia Portal 工程对照和运动学。

## 文件特点

- HTML 单文件，内置 CSS / JS / SVG，无外部脚本、字体或网络资源。
- 教学测试场景：启动自锁、停止优先、急停保持、过载跳闸、光电计数、速度切换、错接线检测。
- 截止 v1 版本，已有浏览器自动交互测试验证上述场景；仍需教师对正式实训接线资料进行人工复核。
