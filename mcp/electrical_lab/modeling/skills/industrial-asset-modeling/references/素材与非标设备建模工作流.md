# 素材与非标设备建模工作流 · v3

## 素材来源优先级
1. 厂家手册/数据表/结构尺寸图/端子定义（技术真值，不直接证明素材可以公开再分发）。
2. 3Dfindit、TraceParts、EPLAN Data Portal、米思米 inCAD Library 等检索入口（遵守账号、下载与转载条款）。
3. 学校或教师自己拍摄、测绘的设备照片与 CAD（仍需确认机构授权和保密范围）。
4. 独立制作 SVG/低面数 3D。SVG 样式可原创设计，但端子必须单独核对。

## 收件清单（有一项就从一项开始）
- 设备正、侧、背面照片，铭牌局部及可读端子特写。
- 全部设备型号、硬件版本、铭牌额定值；无铭牌需明确写 UNKNOWN。
- 量测尺寸与安装点坐标，并明确是测量值还是估算值。
- 电源、信号、气源接口及端子排的官方图纸或经过教师复核的实际接线图。
- 动作视频/动作时序；初始状态、复位、故障、限位、急停及教学环境安全措施。
- 权属及分享边界：`private` 默认，允许对外公开必须有具体许可依据。

## 状态闸门
- draft_only：仅来源条目/示意外观；无资格模拟真实线路。
- visual_reviewed：外观和尺寸经过人工比对；仍可能无端子。
- terminal_reviewed：端子与参数按特定硬件型号/说明书逐个核对。
- simulation_reviewed：动作模型及故障测试全部通过，教师复核。
任何状态都不意味着可在真实设备上直接带电操作。

## 非标单件生成流程
`new_nonstandard_asset` → 保存 JSON → 补证据/端子/授权 → `validate_asset_manifest` → `render_nonstandard_svg` → 教师查看与修正 → （另行实现）动作状态机与接线校验 → 测试 → 离线课件。

## 禁止
- 禁止私自上传学校保密资料至公开仓库或未经确认的第三方服务。
- 禁止宣称仅凭一张照片识别内部接线、实际额定电压、机器人运动安全参数。
- 禁止把“免费可下载 CAD”理解为“可修改、再分发和商用”。
- 禁止将 MCP 生成的示意 SVG 直接作为现场安装、调试或安全操作图。
