# 工业自动化与机器人实训：设备扩展路线与验收规范（v2）

## 已知事实和范围

本工具包包含 46 条设备家族参考条目，不含已核准的型号端子库。状态只分 `catalog_only` 与 `teaching_logic_simulation` 两级。现阶段只有传统荧光灯 `low.fluorescent` 有可交互接线教学仿真，其他条目只是扩展索引。

## 分层架构

- L1 元件目录：类别、品牌、教学行为、潜在信号口、官方资料链接，不能当厂家型号接线表。
- L2 规格层：具体型号、厂商手册 PDF 版本、端子排定义、额定电压、I/O 极性、软件版本、通信接口、适用范围和证据出处。
- L3 教学逻辑层：信号连接网表、常态/切换动作、顺序状态机、超时/互锁、可解释的故障。
- L4 图形层：离线 HTML + SVG 元件外观 + 端子拖拽接线 + 仪表/动画 + 评分。
- L5 工程仿真层（独立项目）：电路瞬态仿真、PLC 虚拟 CPU、机器人运动学/动力学/碰撞、气动流量压力等。需要外部专业引擎，不是 MCP 自动赋予。

## 课程优先级

| 阶段 | 实训项目 | 最小可验收功能 | 注意事项 |
|---|---|---|---|
| 0 已实现 | 传统电感镇流器日光灯 | 拖动接线、线网验证、辉光-预热-点亮与多故障 | 非 SPICE、状态机设定时间非实测 |
| 1 待开发 | 接触器点动/自锁/互锁 | 端子表、辅助触点、常开常闭联动、热继电器、互锁失败场景 | 先核对真实器件型号 |
| 2 待开发 | 西门子 S7-1200/1500 与汇川 H3U/H5U/AM600 | 虚拟 IO、扫描周期、启停逻辑、开路诊断 | 程序/地址/接线不能直接套用不同 CPU 型号 |
| 3 待开发 | 昆仑通态 MCGS HMI | 画面按钮、变量、报警与 PLC 状态机联动 | 标签/驱动/连接参数需要实际设备配置 |
| 4 待开发 | 5/2 电磁阀+双作用气缸 | 阀位、伸缩、限位开关、双电控逻辑、无气源故障 | 教学时序 ≠ 气动动力学数值 |
| 5 待开发 | 伺服/步进+变频器/三相电机 | 使能、脉冲、方向、软硬限位、停止、过载与故障 | 不允许输出真实使能或驱动指令 |
| 6 待开发 | ABB/KUKA 工业机器人 | 关节示意、工位 IO 联动、简单禁行区/互锁可视化 | 运动可达性和安全须 ABB RobotStudio/KUKA 等官方环境验证 |

## 单个设备型号入库前必须提交

1. 品牌、系列、具体完整型号、硬件版本、厂商原始手册下载地址及页码；
2. 端子数、名称、针脚位置、输入/输出类型、供电、电气规格、供电分组与公共端；
3. 故障/复位/急停联锁的定义及厂商安全说明；
4. 至少一份标准接线例、三份错误接线案例、至少一种故障动画；
5. 在 Windows Edge/Chrome 中实际运行交互、自动测试、核对厂家资料及说明未覆盖的风险。

## 真实设备对接的原则

在未提供书面设备型号、网络拓扑、安全评估和教师实时确认流程前，工具只做离线演示和静态分析：**禁止自动发送真实 PLC 写入、机器人运动、伺服使能命令**。所谓“虚拟仿真”不意味着可以绕过急停、防护、互锁以及实验室监管。
