# 工业实训平台 CPU / GPU / 实物运动的分工（v3）

## 1. 概念

- CPU（浏览器 JavaScript 或 WebAssembly）通常执行课堂中的接线网络检查、PLC 教学扫描周期、HMI变量映射、伺服指令模拟、运动学积分（位置/角度）、简单物理碰撞。部分任务也可由GPU加速，但本版不依赖GPU计算。
- GPU（浏览器 WebGL，或2D合成）呈现几何体、贴图、光照、阴影与运动画面；2D离线 SVG 能在没有独立显卡的教学电脑上运行（浏览器图形仍可能使用系统集成GPU）。
- **实际物理设备运行**的控制不是浏览器的 CPU 直接驱动电机，而是 PLC、机器人控制器、变频器或伺服驱动器与真实安全回路。浏览器只负责教学模拟，不主动向设备写控制命令。

## 2. 按需包体

| 项目 | 推荐方案 | 是否需要独显 |
| --- | --- | --- |
| 电工元件接线、荧光灯 | 原创 SVG + JS 状态机 | 不需要 |
| 接触器、电机、单气缸 | SVG / Canvas 2D 位置动画 | 不需要 |
| 非标机构简单空间展示 | 简模 GLB + WebGL（可降级2D） | 通常不需要高端独显 |
| 高细节多轴机器人 | GLB + WebGL + 运动学求解 | 视模型和场景而定 |
| 复杂碰撞、真实气动流体/伺服闭环 | 需要专门物理/动力学引擎和校验 | 视算法与规模而定 |

## 3. 贴图和文件

- 2D 首选 SVG；设备细节照片可以使用经授权 WebP（半透明图片视情况用PNG）。
- 3D 几何可用 glTF/GLB，反复出现的相同设备复用模型；远景减少多边形，选用能满足教学清晰度的低分辨率贴图。
- 对 WebGL 三维模型考虑 KTX2 压缩纹理，但浏览器支持、资源加工链和转换工具均要实际验证。仅有本工具包不能直接生成已验证的贴图。
- 课件按课程装配。例如“非标气动夹具课”只包含PLC、HMI、气缸、电磁阀、传感器和一个机构，而不是全部设备库。

## 4. 时间步建议

- 控制状态或教学运动更新可以取 `20ms` 固定步进（仅为设计参考，不代表真实S7的扫描周期）。
- 动画以 `requestAnimationFrame` 绘制，普通课堂场景目标 30fps，更高配置目标 60fps；应在掉帧时保持状态更新和模拟时间的逻辑一致性。
- PLC 扫描与物理运动仿真采用分别配置的周期、单元测试与验收标准。
